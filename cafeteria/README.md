# Raíz Café · demo de web premium para cafeterías

Demo para vender a cafeterías. El nombre, la dirección (Huancayo), los precios, las reseñas y el WhatsApp son **ficticios**.

## Qué incluye
- Portada con taza animada (vapor, texto circular girando, granos que siguen el mouse).
- Carta por pestañas (calientes, fríos, para acompañar) con botón para agregar al pedido.
- "Arma tu bebida": eliges bebida, tamaño, leche y extras; la taza se llena en vivo y el precio se actualiza.
- Historia "del cafetal a tu taza" que cambia con el scroll, cifras animadas, reseñas, mapa.
- Pedido (recojo o delivery) que se envía completo por WhatsApp con el total.

## Cómo adaptarla a un cliente
Edita `config.js`: nombre, WhatsApp (51 + número), carta, precios y opciones de bebidas.
Dirección, horario y textos están en `index.html`.
