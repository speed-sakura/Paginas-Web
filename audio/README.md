# Resonar · Parlantes premium en Perú

Demo ficticia de página web premium. Todos los nombres, precios y datos son de ejemplo.

- Abre `index.html` en el navegador (no necesita instalar nada).
- Para adaptarla a un cliente, cambia **`config.js`**: nombre, número de WhatsApp (formato 51XXXXXXXXX), productos y precios en soles.
- Textos fijos de las secciones: `index.html`. Colores y tipografías: variables al inicio de `styles.css`.
- Las animaciones respetan la opción "reducir movimiento" del celular.
